# Smart Queue System

A modern real-time queue management platform built with React, Vite, Tailwind CSS, Framer Motion, and Firebase.

Designed for businesses, clinics, schools, government offices, and service centers that need a professional digital queueing experience.

---

# ✨ Features

## 🎫 Queue Generation

* Generate queue numbers dynamically
* Multiple service categories
* Estimated waiting time
* Interactive queue ticket UI

## 🖥️ Live Display System

* Real-time queue monitor
* Animated queue transitions
* Upcoming queue display
* Live digital clock
* System online indicator

## 🛠️ Admin Dashboard

* Call next queue instantly
* Queue monitoring dashboard
* Queue statistics overview
* Active window tracking

## ⚡ Real-Time Experience

* Smooth page transitions
* Micro-interactions and animations
* Live queue updates
* Speech announcement support

## 🎨 Modern UI/UX

* Premium dark-mode interface
* Glassmorphism navbar
* Glow background effects
* Responsive design
* Framer Motion animations

# 🚀 Installation

## 1. Clone Repository

```bash
git clone https://github.com/datsyolowi/smart-queue-system.git
```

---

## 2. Navigate To Frontend

```bash
cd smart-queue-system/frontend
```

---

## 3. Install Dependencies

```bash
npm install
```

---

## 4. Start Development Server

```bash
npm run dev
```

---

# 🔥 Firebase Setup

Create a Firebase project from:

[https://console.firebase.google.com](https://console.firebase.google.com)

Then create:

```plaintext
src/firebase.js
```

and add your Firebase configuration.
